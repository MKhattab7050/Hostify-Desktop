## Deliver
1. **hostify-engine** (bin `hostify-engine`): single instance (named mutex); opens DB, runs `components` status, implements `SiteRuntime` (from core `deploy`) with a **Supervisor**: spawns caddy (Caddyfile regenerated from DB, `caddy run --config … --adapter caddyfile`, graceful reload via `caddy reload` or restart) and cloudflared (`tunnel --no-autoupdate run`, token ONLY via env `TUNNEL_TOKEN`) with `std::process::Command` (no shell, args arrays, `CREATE_NO_WINDOW`), all children in a Windows Job Object with KILL_ON_JOB_CLOSE; crash restart with exponential backoff (cap 60s) and activity-log entries; health loop (HTTP GET per site port, cloudflared connection state via its `--metrics 127.0.0.1:<port>` `/ready` endpoint); port-conflict detection with a friendly `statusDetail`. On startup: `recover_interrupted()` then reconcile (auto-start sites, republished tunnels). Graceful shutdown on Ctrl+C / console close / session end.
2. **Control server** on named pipe `\\.\pipe\hostify-engine-<user SID>` with explicit DACL (current user + SYSTEM only; reject others), newline-delimited JSON-RPC implementing EVERY command in IPC.md (including `system_stats` via `sysinfo`, `site_logs` tail with rotation-aware reading, `list_activity`, settings, `ensure_components`) and pushing events (`site-status`, `deployment-update`, `activity`, `components-progress`) to subscribed clients. Request size limits; unknown methods rejected.
3. **Autostart/service CLI**: `install-task`/`uninstall-task` (per-user Scheduled Task at logon via `schtasks` with an XML definition, no admin), `install-service`/`uninstall-service`/`--service` (Windows Service, needs elevation), `status`. Log rotation (size-based).
4. **src-tauri shell**: register ALL IPC.md commands as `#[tauri::command]` forwarding over the pipe (one reusable client; reconnect), spawn the engine detached if the pipe is absent (look for `hostify-engine.exe` beside the app exe), forward engine events with `app.emit`. `pick_path` via `tauri-plugin-dialog` (directory or zip filter). Tray icon (Open Hostify / Quit window only — hosting continues); closing the window hides to tray when `closeToTray`. `capabilities/default.json` minimal (core:default, dialog open, opener open-url, event listen, webview drag-drop). Strict CSP: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; font-src 'self' data:; img-src 'self' data:; connect-src ipc: http://ipc.localhost`. Window config already set (1180x760).
